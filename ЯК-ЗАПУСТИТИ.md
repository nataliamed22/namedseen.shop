# Named & Seen: як запустити сайт і адмінку

Робиться один раз, приблизно за 30–40 хвилин. Далі сайт живе сам, а ти все змінюєш на namedseen.com/admin.

---

## Крок 1. Акаунт на GitHub

1. Зайди на **github.com** → Sign up. Безкоштовно.
2. Запам'ятай свій логін, наприклад `nataliamed`. Він знадобиться в кроці 3.

## Крок 2. Завантаж проєкт на GitHub

1. На GitHub натисни **+** угорі праворуч → **New repository**.
2. Repository name: `namedseen`. Можна поставити **Private**.
3. Натисни **Create repository**.
4. На сторінці, що відкрилась, натисни посилання **uploading an existing file**.
5. Розпакуй архів `namedseen-site.zip` і перетягни **весь вміст папки** (а не саму папку) у вікно браузера.
6. Внизу натисни **Commit changes**.

## Крок 3. Впиши свій логін в адмінку

1. У репозиторії відкрий файл `src/admin/config.yml` → іконка олівця (Edit).
2. У третьому рядку заміни `OWNER` на свій логін GitHub:
   `repo: nataliamed/namedseen`
3. **Commit changes**.

> Те саме зроби у файлі `tools/cms-config.src.yml`, щоб при майбутніх змінах адмінки логін не загубився.

## Крок 4. Підключи Netlify

1. Зайди на **netlify.com** → Sign up → **Sign up with GitHub**.
2. **Add new site** → **Import an existing project** → **GitHub** → обери `namedseen`.
3. Налаштування підтягнуться самі (build: `npm run build`, publish: `_site`). Натисни **Deploy**.
4. Через хвилину сайт буде онлайн на тимчасовій адресі на кшталт `something.netlify.app`.

## Крок 5. Дозволь адмінці входити через GitHub

Це потрібно, щоб на /admin працювала кнопка «Увійти через GitHub».

**5а. Створи OAuth App на GitHub**
1. GitHub → твоє фото → **Settings** → внизу зліва **Developer settings** → **OAuth Apps** → **New OAuth App**.
2. Заповни:
   - Application name: `Named & Seen admin`
   - Homepage URL: `https://namedseen.com`
   - Authorization callback URL: `https://api.netlify.com/auth/done`
3. **Register application**.
4. Скопіюй **Client ID**. Натисни **Generate a new client secret** і скопіюй **Client secret**.

**5б. Встав їх у Netlify**
1. Netlify → твій сайт → **Site configuration** → **Access & security** → **OAuth**.
2. **Install provider** → GitHub → встав Client ID і Client secret → **Install**.

## Крок 6. Підключи домен namedseen.com

1. Netlify → сайт → **Domain management** → **Add a domain** → `namedseen.com`.
2. Netlify покаже, які записи DNS поставити в реєстратора домену (там, де ти купувала namedseen.com). Зміни їх так, як він підкаже.
3. Протягом години-двох сайт відкриється на namedseen.com, а HTTPS увімкнеться сам.

## Крок 7. Увійди в адмінку

Відкрий **namedseen.com/admin** → **Увійти через GitHub** → дозволь доступ.

## Як працювати в адмінці

**Сторінки.** Головна, Terms, Refunds, Contact і будь-які нові.
- Щоб змінити текст, відкрий сторінку, розгорни потрібний блок і редагуй. Праворуч одразу видно результат.
- Щоб додати блок, натисни «Додати блоки сторінки» внизу списку й обери тип.
- Щоб змінити порядок, тягни блок за ручку ═.
- Щоб сховати блок, не видаляючи, увімкни «Сховати блок».
- Щоб зробити копію сторінки, відкрий її, натисни стрілку біля «Опубліковано» → **Duplicate**.

**Шаблони (товари).**
- Новий шаблон: «Шаблони» → **Новий Шаблон**. Заповни назву, колекцію, статус, обкладинку, галерею, кольори, що входить.
- «Статус → Продається»: з'являється кнопка Buy. «Скоро»: картка в блоці Opening next. «Прихований»: товар зникає із сайту.
- «Головний на сайті»: велика картка першою. Має бути лише один.
- **Посилання на оплату**: сюди встав посилання з WayForPay для цього товару.
- **Canva template link** і **PDF-гайд** показуються тільки покупцю на сторінці «Дякуємо».
- Блоки сторінки товару можна не заповнювати, тоді буде стандартна сторінка. Якщо хочеш іншу, додай свої блоки.

**Сторінка «Дякуємо» після оплати.** Для кожного шаблону вона вже існує за адресою:
`namedseen.com/thank-you/claret/`, `.../thank-you/riviera/` і так далі.
У налаштуваннях товару в WayForPay вкажи цю адресу як **returnUrl**, тоді після оплати покупця поверне саме туди. Сторінка схована від Google.

**Налаштування сайту.** Кольори (палітра з піпеткою), шрифти, стиль і швидкість анімації, пошта, Instagram, реквізити ФОП, меню.

**Публікація.** Натисни **Опублікувати** вгорі. Приблизно за хвилину зміни будуть на сайті.

## Формат картинок

У блоках з картинками є поле «Формат картинки»: квадрат 1:1, вертикальна 4:5 або 3:4, горизонтальна 4:3 або 3:2, широка 16:9, або «оригінальна, без обрізання».
